# Office 문서 왕복 검증

Office는 `web_tests/documents.py`에서 외부 `jakal-hwpx` API로 만든 문서를 사용합니다. 원본 모듈의 샘플이나 별도 코퍼스를 저장소에 포함하지 않습니다.

| 입력 | 통합 검증 |
|---|---|
| 생성한 HWP | 표·수식·그림의 변환 전후 개수, 업로드 원본 보존 |
| 생성한 HWPX 양식·병합 표 | 업로드 → 편집 → 검증 → 다운로드 → 재열기·재업로드 |
| 변환기가 잘못된 첨부 참조를 출력하는 경우 | 변환 결과 검사, 부분 파일 정리, 원본 바이트 보존 |
| 생성한 5쪽 가로 PDF | 페이지 수·방향·미리보기, 원본 보존 |

`test_real_roundtrip.py`는 개체 종류·수, 병합 셀 좌표와 span, 첨부 바이트 해시, 수정하지 않은 텍스트를 비교합니다. 원본 다운로드와 이전 버전도 확인합니다. `test_inline_layout.py`는 줄바꿈·공백·이모지의 정상 위치와 실제 위치 초과를 구별합니다. 실제 사용자 문서는 별도 비공개 환경에서 추가 검증할 수 있습니다.

```bash
python -m pytest web_tests -q
```

wheel과 sdist의 외부 의존성 연결 검사는 [릴리스 안내](../RELEASING.md)를 참고하세요. 이 검사는 한글 프로그램과 모든 문서의 동일 조판을 보장하지 않습니다.
